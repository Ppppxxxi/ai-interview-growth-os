# v0.3.3 Release Notes

## 版本定位

v0.3.3 是首次真实使用信任感增强版。它不改变 v0.3.2 的“聚焦流程页 + 工作台”分流，而是在用户粘贴材料后的确认阶段，补充更清楚的识别反馈和本地保存边界说明。

## 本版本改了什么

- 聚焦流程页输入区增加本地处理说明：当前版本仅保存在本机浏览器，不接真实 LLM，不上传服务器。
- 解析材料后增加识别摘要，展示目标岗位、问题数、追问数、薄弱点和待确认项。
- 对未识别岗位、方向或低置信草稿给出修正建议，但不阻塞用户继续生成下次可用回答。
- 数据管理菜单补充清空本地数据和恢复示例的影响说明。
- 清空数据确认文案改为“我的回答库”，减少内部术语。

## 当前仍不做什么

- 不接真实 LLM。
- 不做登录、数据库和云同步。
- 不做文件上传。
- 不改变同岗位多轮和同方向类似岗位复用的优先验证方向。
