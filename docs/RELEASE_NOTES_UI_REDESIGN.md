# 全站浅色 UI 改版

将已选浅色原型落到现有 React 页面，覆盖完整产品流程。

- 全站侧栏导航、统一页头、图标、输入框、标签和数据管理菜单。
- 开始新面试按录入、确认问题、优化回答、保存分阶段展开；岗位信息可选。
- 识别与生成一次展示一个问题，保留编辑、采用、修改后采用及暂不保存。
- 岗位详情拆成面试记录、下次可用回答、岗位准备，记录支持切换及折叠。
- 回答库使用列表与阅读区布局；详细筛选、改写依据、版本和反馈按需展开。
- 面试复盘包含个人能力画像、关键词、方向标签及复盘记录；没有评分的维度不填虚构分数。
- 无数据仍默认进入录入页，导航保持可见。

沿用浏览器本地保存及现有 Agent；没有引入登录、云同步或真实 LLM。

## 验证

- Vitest 测试和 Vite 生产构建。
- 浏览器录入示例、解析、采用、保存到回答库。
- 回答关键词检索、无结果、清空筛选、编辑并保存新版本。
- 岗位详情、能力雷达、无数据页面及桌面/窄屏布局。
